# pascal-agenda-faa

Online scheduling API for clinics and salons (multi-tenant), in Object Pascal, building on
both Delphi and Lazarus/FPC. It is built only on the `*-faa` libraries
(pascal-api-infra-faa, pascal-db-faa, pascal-jsonmapper-faa, pascal-common-faa,
pascal-redis-faa, pascal-amqp-faa), to validate them in a real application and to find
what they lack.

Status: design only. Scope, milestones and library candidates: [`docs/design.md`](docs/design.md).
